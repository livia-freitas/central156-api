# Central 156 - API
![CI](https://github.com/livia-freitas/central156-api/actions/workflows/ci.yml/badge.svg)

API REST em **Java/Spring Boot** sobre os dados abertos da central 156 de Curitiba (o canal de atendimento da Prefeitura). 

## Como rodar
*Requisitos*: Java 25.

*No Windows*: `.\mvnw.cmd spring-boot:run` 

*No Linux/Mac*: `./mvnw spring-boot:run`
